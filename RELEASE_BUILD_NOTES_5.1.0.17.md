# Build notes for 5.1.0.17

Set `-DAMNEZIAVPN_VERSION:STRING=5.1.0.17` and use the existing prewarmed Qt/MSVC and Android toolchains.

For Android preserve base `APP_ANDROID_VERSION_CODE=2191` and pass `-DAPP_ANDROID_VERSION_CODE_OFFSET=6`, yielding code 2197; do not override the base code.

The embedded Russian network list `client/resources/mayak/ru_ipv4.txt` is generated by `mayak/tools/gen_ru_networks.py` from the public RIPE NCC file delegated-ripencc-extended-latest (source date and SHA-256 in the list header) with `--min-share 1.0 --min-prefix 32 --priority-from-snapshot mayak/tools/ru_priority_snapshot.json`.
